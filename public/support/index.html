Retro Devtools

Support and privacy for CHREditor, NESgfx and ChannelF Graphics Editor — graphics tools for classic games consoles.

Getting help

These are hobby projects, and support is handled by email. Write to info@codeninja.dk. Please say which app and which version you are running — you will find the version under the app's name in the menu bar, in the About window.

When reporting a problem

These four things let a problem be reproduced, which is almost always the difference between a fix and a long conversation:

  • Which app, and its version from the About window.
  • Your macOS version.
  • What you did, and what happened instead of what you expected.
  • The file it happened with, if the file is not private — a truncated or unusual file is a common cause, and having it makes the fix quick.

Common questions

What files do these apps work with?

CHREditor opens .chr tile files, raw .bin data and .nes ROMs in the iNES and NES 2.0 formats. NESgfx works with its own project documents, and can import and export nametables, attribute tables, CHR tilesets and palettes as separate files.

ChannelF Graphics Editor exports pictures as assembler source — .inc or .asm files containing .byte data, in hexadecimal or binary. It can re-open the files it wrote, import a PNG or JPEG to trace, and open the full-screen “multicolor” pictures produced by Kurt Woloch’s ChannelF_Converter.

Can I edit a ROM directly?

Yes. CHREditor finds the graphics inside an iNES or NES 2.0 ROM, lets you edit them, and writes your changes back into the ROM in place. If the ROM has several CHR banks, each one appears in the Bank menu. Keep a copy of the original — editing writes to the file you opened.

Why does the NES only allow four colours per tile?

That is the hardware, not the app. An NES background tile uses four colours, and colour is assigned in blocks of 32 by 32 pixels rather than per tile. NESgfx shows those block boundaries as an optional grid so you can see exactly where they fall.

In ChannelF Graphics Editor, why only four colours — and why do my colours turn white?

Again, the hardware. The Fairchild Channel F shows two bits per pixel: four colours per line, made of one background plus three plot colours (red, blue and green). The background is chosen per scanline and can be light grey, light green, light blue or black. When a line’s background is black, its three plot colours are all displayed as white. The editor follows the same rules on screen, so what you see matches the console.

Why can’t I edit a multicolor picture I opened?

A full-screen multicolor picture (Kurt Woloch's format, Veswiki) carries a different background colour on every scanline, which the editor’s single palette can’t represent for editing. Those files open read-only so you can view them accurately; start a new drawing to make something editable.

Which macOS versions are supported?

CHREditor needs macOS 11 or later. NESgfx needs macOS 12.6 or later. ChannelF Graphics Editor needs macOS 11 or later.

Privacy

CHREditor, NESgfx and ChannelF Graphics Editor do not collect, store or transmit any personal data.

  • There is no analytics, no tracking and no advertising.
  • None of the apps create an account or ask you to sign in.
  • None of the apps send anything over the network. The files you open and save stay on your own Mac, and nothing about them is reported anywhere.
  • If you write to support, whatever you choose to send is used only to answer you, and is not passed on to anyone.
